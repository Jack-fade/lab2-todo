# lab2-todo 命令行待办事项管理器

使用 Python 标准库实现的命令行待办事项管理工具，无需安装任何额外依赖。

## 功能

- **添加任务**：输入任务内容即可创建任务
- **查看任务**：列出所有任务（ID、状态、内容、创建时间）及完成统计
- **标记完成**：按任务 ID 将任务标记为已完成
- **删除任务**：按任务 ID 删除任务（需二次确认）
- **数据保存**：自动保存到同目录下的 `todos.json`，下次启动自动读取

## 运行环境

- Python 3.8+（无需任何第三方库）

## 启动命令

```bash
python3 todo.py
```

## 使用说明

启动后会出现中文菜单：

```
===== 菜单 =====
1. 查看任务
2. 添加任务
3. 标记完成
4. 删除任务
5. 退出
```

按提示输入数字选择操作：

1. **查看任务**：显示任务列表和完成统计
2. **添加任务**：输入任务内容后回车即可保存
3. **标记完成**：输入任务 ID 后回车，将其标记为已完成
4. **删除任务**：输入任务 ID，确认后删除
5. **退出**：保存后退出程序

## 数据文件

任务数据保存在程序同目录的 `todos.json` 中，可直接用文本编辑器查看或删除该文件来清空所有任务。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `todo.py` | 主程序 |
| `todos.json` | 任务数据文件（首次运行添加任务后自动生成） |
| `README.md` | 本说明文档 |
